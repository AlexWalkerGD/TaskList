## 📖 About the Project

**Task List** is a simple web application that allows users to manage their daily tasks efficiently.  
You can add new tasks, mark them as completed, delete individual tasks, or clear the entire list.

🔗 **Access the live project:** [Click here](https://alexwalkergd.github.io/TaskList/)

## 🚀 Features

- 📝 Add new tasks
- ✔️ Mark tasks as completed
- 🗑️ Delete individual tasks
- 🧹 Clear all tasks from the list
- 📱 Responsive and user-friendly interface

## ⚙️ How to Run Locally

1. Clone this repository:

    ```bash
    git clone https://github.com/alexwalkergd/TaskList.git
    ```

2. Access the project folder:

    ```bash
   cd TaskList
    ```

3. Open the `index.html` file directly in your browser  
   *(or use a VS Code extension like “Live Server” to run it locally)*
